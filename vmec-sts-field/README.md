# VMEC grid-field comparison

This comparison uses only the synthetic five-period rotating ellipse generated by `TestVmecField.writewout` in the ASCOT5 native unit tests. It contains no measured equilibrium or machine data.

`before-after-synthetic.png` compares the field and normalized radius returned by ASCOT's `libascot` B_STS evaluator with independent direct VMEC Fourier sums. Both implementations use linear radial coefficients on the VMEC full and half meshes, extended beyond the last surface. The dotted line marks normalized toroidal flux s = 1, the last closed flux surface. RMS means root mean square; all errors and normalized fluxes are dimensionless. The reference normalized radius is sqrt(s). The exterior continuation is not a vacuum-field solution.

The cylindrical grid has 50 radial by 50 vertical points, with 18 toroidal planes per 72-degree period and 120 poloidal seed angles. At each flux surface, 4,000 reproducible angle pairs are sampled; only points inside the rectangular grid are retained, identically before and after. The retained count and fraction, maximum errors and RMS errors are in `synthetic-field-errors.json`. At least 95.3% are retained near the edge.

Before: 835db650 (fork main after the axis-flux fix, before direct VMEC evaluation). After: 9358b5f7. The native regression fails on the old template at all three tested surfaces; all 17 native unit tests pass with the new template.

To reproduce, install the fixed repository and its libascot, with NumPy 2.2.6, unyt 3.0.4, netCDF4 and matplotlib. Obtain the old template with `git show 835db650:a5py/templates/importdata.py > importdata-before.py`, then run `MPLBACKEND=Agg python field-evidence.py` next to that file. The script generates the fixture, JSON and plot from scratch.
